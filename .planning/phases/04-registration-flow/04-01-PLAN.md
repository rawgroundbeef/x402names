    Create `apps/api/src/lib/jobs/queue.ts` - Simple in-memory job queue:

    - `activeTimers` Map to track setTimeout handles (for cleanup/testing)
    - `enqueueJob(jobId: string, processFn: () => Promise<void>, delayMs?: number)`:
      - Schedules processFn via setTimeout with optional delay
      - Stores timer handle in activeTimers map
      - Returns void
    - `cancelJob(jobId: string)`: Clears timeout if exists
    - `clearAllJobs()`: Clears all active timers (for graceful shutdown and testing)
    - `getActiveJobCount()`: Returns number of active timers

    Create `apps/api/src/lib/jobs/registration.ts` - Registration job processor:

    Import DomainRegistrar, ContactInfo from registrar/types. Import registrationJobs, domains from db/schema. Import env for contact info. Import enqueueJob from queue.

    Export `getDefaultContactInfo()`: Returns ContactInfo object built from REGISTRAR_CONTACT_* env vars.

    Export `createJobProcessor(registrar: DomainRegistrar, db: BunSQLiteDatabase<any>)`:
    Returns an object with a `processJob(jobId: string)` async method. This factory pattern enables dependency injection for testing.

    The processJob method:

    ```
    Constants:
      MAX_ATTEMPTS = 3
      BASE_DELAY_MS = 1000

    1. Load job from registrationJobs by id
    2. Guard: if not found OR state !== 'processing', log and return
    3. Guard: if attempts >= MAX_ATTEMPTS, mark as failed and return

    try {
      // Step 1: Payment verified (already done by middleware)
      updateJob({ progress: 33, currentStep: 'payment_verified' })

      // Step 2: Submit to registrar
      updateJob({ progress: 66, currentStep: 'registrar_submitted' })
      const contactInfo = getDefaultContactInfo()
      const result = await registrar.register(job.domainName, 1, contactInfo)

      if (!result.success) {
        throw new Error(`Registration failed for ${job.domainName}`)
      }

      // Step 3: Create domain record
      const validation = validateDomain(job.domainName)
      db.insert(domains).values({
        name: validation.sld,
        tld: validation.tld,
        status: 'registered',
        ownerWallet: job.ownerWallet,
        targetUrl: job.targetUrl || null,
        paymentId: job.paymentId,
        registrarOrderId: result.orderId || result.transactionId,
        createdAt: new Date(),
        updatedAt: new Date(),
      }).run()

      // Mark succeeded
      db.update(registrationJobs)
        .set({ state: 'succeeded', progress: 100, currentStep: 'registered', registrarOrderId: result.orderId || result.transactionId, completedAt: new Date() })
        .where(eq(registrationJobs.id, jobId))
        .run()

    } catch (error) {
      const nextAttempt = (job.attempts || 0) + 1
      const errorMessage = error instanceof Error ? error.message : String(error)

      if (nextAttempt >= MAX_ATTEMPTS) {
        // Mark as permanently failed
        db.update(registrationJobs)
          .set({ state: 'failed', error: errorMessage, errorCode: 'max_retries_exceeded', completedAt: new Date(), attempts: nextAttempt })
          .where(eq(registrationJobs.id, jobId))
          .run()
      } else {
        // Schedule retry with exponential backoff: 2^attempt * base
        const delayMs = Math.pow(2, nextAttempt) * BASE_DELAY_MS
        const nextRetryAt = new Date(Date.now() + delayMs)

        db.update(registrationJobs)
          .set({ attempts: nextAttempt, nextRetryAt })
          .where(eq(registrationJobs.id, jobId))
          .run()

        // Schedule retry via queue
        enqueueJob(jobId, () => processJob(jobId), delayMs)
      }
    }
    ```

    IMPORTANT implementation notes:
    - Use synchronous Drizzle operations (.run(), .get(), .all()) - do NOT await them
    - The only async operation is `registrar.register()` - that one needs await
    - Import `eq` from 'drizzle-orm' for where clauses
    - Import `validateDomain` from '../validation/domain' for domain parsing
    - Use `import { env } from '../../config/env'` for contact info
