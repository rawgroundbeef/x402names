    2. Create `apps/api/src/docs/error-catalog.json` with ALL error codes used across the API. Audit every `createProblemResponse` call and `createValidationProblem` usage across the codebase to build the complete list.

       Format each entry as:
       ```json
       {
         "code": "ERROR_CODE",
         "type": "error:type_string",
         "status": 400,
         "title": "Human Title",
         "description": "What this error means",
         "category": "validation|payment|rate_limiting|registration|server",
         "retryable": true|false,
         "example": { ... full response body example ... }
       }
       ```

       Categories and their errors (audit the codebase to capture all of these):

       **rate_limiting:**
       - RATE_LIMIT_EXCEEDED (429) — Too many requests from IP. Retryable: true. Include `responseHeaders: { "Retry-After": "Seconds to wait" }`

       **validation:**
       - VALIDATION_ERROR (400) — Generic Zod schema validation failure. Retryable: false.
       - DOMAIN_INVALID_FORMAT (400) — Domain name fails format rules. Retryable: false.
       - DOMAIN_UNSUPPORTED_TLD (400) — TLD not in supported list. Retryable: false.
       - URL_INVALID_FORMAT (400) — URL cannot be parsed. Retryable: false.
       - URL_SCHEME_UNSUPPORTED (400) — Non-http/https protocol. Retryable: false.
       - URL_LOCALHOST_REJECTED (400) — Localhost URL. Retryable: false.
       - URL_PRIVATE_ADDRESS (400) — Private IP or metadata endpoint. Retryable: false.
       - URL_CREDENTIALS_REJECTED (400) — URL has embedded auth. Retryable: false.
       - URL_TOO_LONG (400) — URL exceeds 2048 chars. Retryable: false.

       **payment:**
       - PAYMENT_REQUIRED (402) — No payment header provided. Retryable: true (with payment).
       - INSUFFICIENT_PAYMENT (402) — Payment amount too low. Retryable: true (with correct amount).
       - INVALID_PAYMENT (400) — Payment header cannot be decoded. Retryable: false.
       - PAYMENT_ALREADY_USED (409) — Payment ID already processed (replay). Retryable: false.

       **registration:**
       - DOMAIN_UNAVAILABLE (409) — Domain already taken. Retryable: false.
       - DOMAIN_NOT_FOUND (404) — Domain not in our system. Retryable: false.
       - NOT_DOMAIN_OWNER (403) — Wallet doesn't match domain owner. Retryable: false.
       - PREMIUM_DOMAIN (400) — Premium domains not supported. Retryable: false.
       - PRICING_NOT_AVAILABLE (400) — TLD pricing not configured. Retryable: false.
       - TLD_NOT_FOUND (404) — TLD not found. Retryable: false.

       **server:**
       - SERVER_ERROR (500) — Unexpected internal error. Retryable: true.
       - REGISTRAR_UNAVAILABLE (503) — Registrar API down. Retryable: true.
       - REGISTRAR_ERROR (502) — Registrar returned error. Retryable: true.
       - REGISTRAR_AUTH_ERROR (503) — Registrar auth failed. Retryable: true.

       Wrap in a top-level object:
       ```json
       {
         "version": "1.0.0",
         "generated": "2026-02-04",
         "categories": ["rate_limiting", "validation", "payment", "registration", "server"],
         "errors": [ ... all entries ... ]
       }
       ```

       For each entry, include a realistic `example` field showing the exact JSON response body an agent would receive.

    3. Create `apps/api/src/routes/errors.ts`:

       - `GET /:code` — returns a single error entry by code (case-insensitive lookup). Return 404 if code not found.
       - Export default router

       - Mount: `app.route('/errors', errors)` (add BEFORE the root endpoint)
