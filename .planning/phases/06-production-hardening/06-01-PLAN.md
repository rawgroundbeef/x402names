  <name>Task 1: Install hono-rate-limiter and create rate limiting middleware</name>
  <files>
    apps/api/package.json
    apps/api/src/lib/middleware/rate-limit.ts
    apps/api/src/config/env.ts
  </files>
  <action>
    1. Install hono-rate-limiter:
       ```
       cd apps/api && bun add hono-rate-limiter@0.5
       ```

    2. Add BEHIND_PROXY env var to `apps/api/src/config/env.ts`:
       ```typescript
       BEHIND_PROXY: bool({ default: false }),
       ```
       This controls whether to trust X-Forwarded-For headers for IP extraction.

    3. Create `apps/api/src/lib/middleware/rate-limit.ts` with:
       - Import `rateLimiter` from `hono-rate-limiter`
       - Import `env` from `../../config/env`
       - Export `createReadLimiter()` factory function that returns a Hono middleware
       - Configuration:
         - `windowMs`: 60 * 1000 (1 minute sliding window)
         - `limit`: 100 (100 requests per minute per IP)
         - `standardHeaders`: `'draft-6'`
         - `keyGenerator`: Function that extracts client IP. If `env.BEHIND_PROXY` is true, use first entry from `X-Forwarded-For` header (split by comma, trim). Otherwise fall back to `X-Real-IP` header, then `'unknown'`.
         - `handler`: Custom 429 handler that returns RFC 9457 Problem Details JSON:
           ```json
           {
             "type": "error:rate_limit_exceeded",
             "title": "Rate Limit Exceeded",
             "status": 429,
             "detail": "Too many requests. Please try again later."
           }
           ```
           Set `Retry-After` header to `'60'` (string, seconds).

    Do NOT add X-RateLimit-Remaining or proactive quota headers (per CONTEXT decisions).
    Do NOT rate limit paid endpoints - this middleware is only for read endpoints.
  </action>
  <verify>
    - `bun run --bun apps/api/src/lib/middleware/rate-limit.ts` compiles without errors (no syntax issues)
    - `createReadLimiter` is exported and callable
  </verify>
  <done>
    Rate limiting middleware module exists with configurable IP extraction and RFC 9457 compliant 429 responses.
  </done>
</task>
