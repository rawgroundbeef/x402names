<objective>
Create the multi-domain redirect server that routes incoming HTTP requests by hostname, performs 301 redirects to target URLs, and serves appropriate pages for unconfigured or unknown domains.

Purpose: This is the core delivery mechanism for the product -- when a registered domain receives traffic, it redirects to the owner's target URL. Without this, registered domains have no observable effect.

Output: A working redirect server on a configurable port that looks up domains in a cached database layer and returns 301 redirects, holding pages, or landing pages depending on domain state.
</objective>

  <action>
Install node-cache: `cd apps/api && bun add node-cache`

Create `apps/api/src/redirect/cache.ts`:
- Export a `DomainCache` class wrapping node-cache with stdTTL of 300 seconds and checkperiod of 60 seconds
- Methods: `get(domain: string): string | null` (returns cached targetUrl or null), `set(domain: string, targetUrl: string): void`, `del(domain: string): void`, `flush(): void`
- Constructor accepts optional `{ ttl?: number }` for test flexibility
- The cache stores domain name -> targetUrl mappings

Create `apps/api/src/redirect/server.ts`:
- Export `createRedirectApp(db: BunSQLiteDatabase<any>, cache: DomainCache)` factory function that returns a Hono app
- Use Hono's `getPath` constructor option to route by hostname: `getPath: (req) => { const url = new URL(req.url); const host = (req.headers.get('host') || url.hostname).split(':')[0]; return '/' + host + url.pathname; }`
- Strip port from host header (important for development where port is appended)
- Route `/:domain{.+\\..+}/*` to handle domain requests (regex ensures host has at least one dot, indicating a real domain):
  1. Extract domain from host (already in path via getPath)
  2. Check cache first via `cache.get(domain)`
  3. On cache miss, query DB: `db.select().from(domains).where(eq(domains.name, domain)).get()`
  4. If domain found with status 'live' or 'registered' and has targetUrl: cache it, then 301 redirect
  5. If domain found but no targetUrl: return holding page HTML (simple, clean page saying "This domain is registered but not configured yet" with domain name shown)
  6. If domain not found in DB: return landing page HTML ("This domain is available for registration" with link to API docs)
- Build redirect URL preserving path and query string: parse targetUrl as URL base, set pathname to the request subpath (everything after the domain in getPath result), set search to original request search params. Return `c.redirect(redirectUrl.toString(), 301)`
- Add ACME challenge route placeholder: `app.get('/.well-known/acme-challenge/:token', ...)` that returns 404 for now (will be wired to SSL in future)
- Handle root requests without a valid domain host pattern as a simple JSON info response

IMPORTANT: Do NOT use x402 middleware or payment for this server. It is a public-facing redirect server with no authentication.
