Create `apps/api/src/routes/domains/url-update.ts`:
- Export `createUrlUpdateRoutes(db: BunSQLiteDatabase<any>, domainCache: DomainCache)` factory function
- Import DomainCache from redirect/cache, decodePaymentSignatureHeader from @x402/core/http, domains from db/schema, and error helpers

  PATCH `/:name/url` endpoint:
  1. Validate request body with zod: `{ targetUrl: z.string().url() }` -- use zValidator with validationErrorHook
  2. Extract domain name from params (`:name`)
  3. Look up domain in database: `db.select().from(domains).where(eq(domains.name, domainName)).get()`
  4. If not found, return 404 with createProblemResponse('error:domain_not_found', 'Domain Not Found')
  5. Extract payment header (same pattern as register.ts): check for 'payment-signature' or 'x-payment' header
  6. If no payment header, return 402 with createProblemResponse('error:payment_required', 'Payment Required', 'URL update costs 2.00 USDC')
  7. Decode payment using decodePaymentSignatureHeader (same pattern as register.ts)
  8. Extract payer wallet from payment payload (same extraction pattern as register.ts)
  9. Validate payment amount: extract amount, convert from micro-USDC (divide by 1_000_000), require >= 2.00 USDC
  10. If insufficient, return 402 with createProblemResponse('error:insufficient_payment', detail: 'URL update requires 2.00 USDC')
  11. Verify ownership: compare domain.ownerWallet.toLowerCase() with payerWallet.toLowerCase()
  12. If not owner, return 403 with createProblemResponse('error:not_domain_owner', 'Forbidden', 'Only the domain owner can update the URL')
  13. Idempotency check: if domain.targetUrl === targetUrl, return 200 with `{ success: true, updated: false, reason: 'url_already_set', domain: domainName, targetUrl }`
  14. Update database: `db.update(domains).set({ targetUrl, updatedAt: new Date() }).where(eq(domains.name, domainName)).run()`
  15. Invalidate cache: `domainCache.del(domainName)`
  16. Record payment for replay protection: call recordPayment with paymentId, wallet, amount '2.00', network, domain
  17. Return 200 with `{ success: true, updated: true, domain: domainName, targetUrl, previousUrl: domain.targetUrl }`

  The flat $2.00 fee is hardcoded as a constant: `const URL_UPDATE_FEE_USDC = 2.00`
