Create `apps/api/src/services/dns.ts`:
- Export `createDnsService(registrar: DomainRegistrar, serverIp: string)` factory function
- The returned service object has these methods:

  `configureDomain(domain: string)`: Configures DNS A records for a domain using read-modify-write pattern:
  1. Call `registrar.getDnsRecords(domain)` to get existing records
  2. Filter out any existing A records for '@' and 'www' hosts (we're replacing these)
  3. Merge with new A records: `{ type: 'A', name: '@', value: serverIp, ttl: 300 }` and `{ type: 'A', name: 'www', value: serverIp, ttl: 300 }`
  4. Call `registrar.setDnsRecords(domain, mergedRecords)` with the complete set
  5. Return `{ configured: true, records: [the two A records added] }`
  This preserves existing MX, TXT, CNAME records while setting/replacing A records.

  `getDnsInfo(domain: string, serverIp: string)`: Returns DNS configuration info for a domain:
  - Returns `{ domain, serverIp, records: [{ type: 'A', host: '@', value: serverIp, ttl: 300 }, { type: 'A', host: 'www', value: serverIp, ttl: 300 }], instructions: [...] }`

  `verifyDns(domain: string, serverIp: string)`: Checks if DNS is properly configured:
  1. Use `Bun.dns.resolve(domain)` (Bun built-in DNS resolver, no external deps) to resolve the domain
  2. Check if any returned IP matches serverIp
  3. Return `{ domain, verified: boolean, resolvedIps: string[], expectedIp: serverIp, message: string }`
  4. If resolution fails (domain doesn't resolve), return verified: false with appropriate message

Update `apps/api/src/lib/jobs/registration.ts`:
- Add `dnsService` parameter to `createJobProcessor(registrar, db, dnsService?)` -- make it optional for backward compatibility
- After successful registration (after domain record insert, before marking job succeeded), add DNS configuration step:
  1. Update job progress to 80, currentStep: 'dns_configuring'
  2. If dnsService is provided, call `dnsService.configureDomain(job.domainName)`
  3. On success, update domain status from 'registered' to 'live': `db.update(domains).set({ status: 'live' }).where(eq(domains.name, job.domainName)).run()`
  4. On DNS failure, log warning but do NOT fail the job -- domain is still registered, DNS can be retried later. Keep domain status as 'registered'.
  5. Update progress to 100, currentStep: 'completed'
- DNS failure should never cause a registration to fail. Log the error and continue. The domain is registered with the registrar, DNS is a best-effort enhancement.

  2. Look up domain in database, 404 if not found
