       - Import describe, test, expect from bun:test
       - Import the Hono app from the main index.ts (or create app inline for isolated testing)
       - Use app.request() method (Hono's built-in test helper -- no need for a real HTTP server):
         ```typescript

         const body = await res.json();
         ```

       Test cases:
       a) "GET /health returns 200":
          - Assert response status is 200

       b) "GET /health returns correct shape":

          - Assert status is "ok"

       c) "GET / returns API info":

          - Assert body has version field

       NOTE on test isolation: The health test imports the app which imports the db module, which will try to create/open a real SQLite file. Either:
       - Set DATABASE_URL env to a temp file before importing
       - Or use NODE_ENV=test and point to a test-specific database

The simplest approach: `process.env.DATABASE_URL = ':memory:'` at the very top of the file, before any imports.        Actually, the cleanest approach for Hono testing:
       - Create the Hono app in a factory function or import from a module that doesn't auto-connect to the database
       - OR: Accept that tests will use a real temp file and clean up after

       Use whichever approach is simpler. If the app module eagerly initializes the DB, set DATABASE_URL to a temp path in a test setup script or at the top of the test file.
