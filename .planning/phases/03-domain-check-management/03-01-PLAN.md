  <action>
    1. Install dependencies:
       ```
       cd apps/api && bun add tldts @hono/zod-validator
       ```

    2. Create `apps/api/src/lib/validation/domain.ts`:
       - Import `parse` from `tldts`
       - Import `z` from `zod`
       - Create `validateDomain(input: string)` function that returns `{ valid: boolean; domain?: string; sld?: string; tld?: string; error?: string }`:
         - Use `parse(input, { allowPrivateDomains: false })` to parse domain
         - Reject if no valid domain or publicSuffix extracted
         - Reject if `parsed.subdomain` is present (second-level domains only)
         - Check label length <= 63 chars (RFC 1035)
         - Check total domain length <= 253 chars (RFC 1035)
         - Check character validity with `/^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$/i` (no leading/trailing hyphens)
         - Lowercase and trim input before parsing
         - Return `{ valid: true, domain: parsed.domain, sld: parsed.domainWithoutSuffix, tld: parsed.publicSuffix }` on success
       - Create Zod schema `domainValidator` (z.string() with transform to lowercase + trim, then refine using validateDomain)
       - Create `batchCheckSchema` = `z.object({ domains: z.array(domainValidator).min(1).max(10) })`
       - Export: validateDomain, domainValidator, batchCheckSchema

    3. Create `apps/api/src/lib/errors.ts`:
       - Define `ProblemDetails` interface: `{ type: string; title: string; status: number; detail: string; instance?: string }`
       - Create `createProblemResponse(c, status, type, title, detail)` helper that builds RFC 9457 JSON response
       - Create Hono `onError` handler function `problemDetailsErrorHandler` that:
         - Catches HTTPException -> maps to ProblemDetails with `type: "error:{status_code}"`
         - Catches RegistrarUnavailable -> returns 503 with `type: "error:registrar_unavailable"`
         - Catches RegistrarError subclasses -> maps to appropriate status codes
         - Catches unknown errors -> returns 500 with `type: "error:internal"`
         - Includes `instance` from `x-request-id` header if present
       - Create `validationErrorHook` for @hono/zod-validator that returns RFC 9457 formatted validation errors with `type: "error:validation"`
       - Import error types from `../integrations/registrar/types`
       - Export: ProblemDetails, createProblemResponse, problemDetailsErrorHandler, validationErrorHook

    4. Create `apps/api/src/lib/validation/__tests__/domain.test.ts`:
       - Test validateDomain with valid domains: "example.com", "my-site.io", "a.net"
       - Test rejection of subdomains: "sub.example.com"
       - Test rejection of invalid characters: "exam ple.com", "exam!ple.com"
       - Test rejection of leading/trailing hyphens: "-example.com", "example-.com"
       - Test label length limit: 64-char label rejected, 63-char label accepted
       - Test total length limit: 254-char domain rejected
       - Test lowercase normalization: "EXAMPLE.COM" -> "example.com"
       - Test empty/null input handling
       - Aim for 10-15 tests covering validation edge cases
  </action>
