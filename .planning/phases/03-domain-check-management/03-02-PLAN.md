       - Import `parse` from `tldts`
       - Import `isSupportedTld` from config/tlds
       - Create `generateSuggestions(domain: string, count: number = 5): string[]`:
         - Parse domain with tldts to extract sld (second-level domain) and tld
         - Strategy 1 - Common prefixes: "get", "my", "the", "try", "use" -> `${prefix}${sld}.${tld}`
         - Strategy 2 - Common suffixes: "app", "hq", "now", "hub", "pro" -> `${sld}${suffix}.${tld}`
         - Strategy 3 - Alternative TLDs: try .com, .io, .co, .net, .org, .app, .dev (skip the original TLD, only include TLDs that are in our supported list via isSupportedTld)
         - Strategy 4 - Hyphenated: if sld has no hyphen, add `get-${sld}.${tld}` and `${sld}-app.${tld}`
         - Deduplicate, filter out the original domain, shuffle for variety, return first `count` results
       - Export: generateSuggestions

    2. Create `apps/api/src/routes/domains/check.ts`:

       - POST `/` (mounted at /domains/check):
         - Validate request body with zValidator('json', batchCheckSchema, validationErrorHook)
         - For each domain in the validated array, run in parallel with Promise.all:
           a. Call validateDomain(domain) - if invalid, return { domain, available: false, error: validation.error }
           b. Check if TLD is supported via isSupportedTld(tld) - if not, return { domain, available: false, error: "Unsupported TLD" }
           c. Call registrar.checkAvailability(domain) for the full domain string
           d. If available: look up pricing via getTldPricing(tld), return { domain, available: true, price: { registration: priceUsdc, renewal: renewalUsdc, currency: "USDC" } }
           e. If unavailable: generate suggestions via generateSuggestions(domain), return { domain, available: false, suggestions: [...] }
           f. If registrar throws RegistrarUnavailable: return { domain, available: false, error: "Registrar temporarily unavailable" }
         - Return `{ results: [...] }`

       - Handle premium domains: if registrar returns isPremium=true, set price to null with note "Premium domain - contact for pricing"
