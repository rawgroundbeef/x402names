**Replay protection** (`apps/api/src/integrations/payment/replay-protection.ts`):

Create three exports:

1. `recordPayment(db: BunSQLiteDatabase, payment: { paymentId: string; walletAddress: string; amount: string; network: string; domain?: string }): void`
   - Insert into paymentRecords table using Drizzle
   - Catch UNIQUE constraint violation on payment_id
   - On UNIQUE violation: throw `DuplicatePaymentError`
   - On other errors: re-throw

   IMPORTANT: Drizzle with bun:sqlite is SYNCHRONOUS, not async. The `db.insert().values()` call does NOT return a Promise -- it executes immediately. Do NOT use async/await with the insert. The function signature should NOT be async.

2. `hasPaymentBeenUsed(db: BunSQLiteDatabase, paymentId: string): boolean`
   - Query paymentRecords for matching payment_id
   - Return true if found, false if not
   - Also synchronous (not async)

3. `DuplicatePaymentError extends Error`:
   - Constructor accepts `paymentId: string`
   - Message: `Payment ID ${paymentId} has already been used`
   - Set `Object.setPrototypeOf(this, DuplicatePaymentError.prototype)`

Import the db type from drizzle-orm/bun-sqlite. Import paymentRecords from schema. Import eq from drizzle-orm for query conditions.

NOTE: Accept `db` as a parameter (dependency injection) rather than importing the singleton. This allows tests to pass in-memory databases.
