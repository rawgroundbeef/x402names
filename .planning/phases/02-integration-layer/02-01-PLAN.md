Create `apps/api/src/integrations/registrar/types.ts` with:

1. **Type definitions** for all registrar data structures:
   - `DomainAvailability`: `{ domain: string; available: boolean; isPremium: boolean }`
   - `DomainPrice`: `{ domain: string; registrationPrice: number; renewalPrice: number; currency: 'USD' }` (USD = USDC at 1:1 peg, no conversion needed)
   - `ContactInfo`: Required fields for domain registration (firstName, lastName, address1, city, stateProvince, postalCode, country, phone, email). These are ICANN requirements -- every registrar needs them.
   - `RegistrationResult`: `{ success: boolean; domain: string; transactionId: string; orderId?: string }`
   - `DomainStatus`: `{ domain: string; status: 'active' | 'expired' | 'pending' | 'unknown'; expiresAt?: Date; createdAt?: Date; nameservers?: string[] }`
   - `DnsRecord`: `{ type: 'A' | 'AAAA' | 'CNAME' | 'URL' | 'URL301' | 'FRAME'; name: string; value: string; ttl?: number }`
     - Include URL redirect types (URL, URL301, FRAME) because Namecheap supports URL forwarding via DNS records -- this is how Phase 5 will implement redirects.

2. **Abstract class `DomainRegistrar`** with 6 abstract methods:
   - `checkAvailability(domain: string): Promise<DomainAvailability>`
   - `getPrice(domain: string): Promise<DomainPrice>`
   - `register(domain: string, years: number, contactInfo: ContactInfo): Promise<RegistrationResult>`
   - `getStatus(domain: string): Promise<DomainStatus>`
   - `setDnsRecords(domain: string, records: DnsRecord[]): Promise<void>`
   - `getDnsRecords(domain: string): Promise<DnsRecord[]>`

   Use abstract class (NOT interface) because interfaces disappear at runtime and cannot be used as DI tokens or with instanceof.

3. **Error class hierarchy** with proper prototype chain:
   - `RegistrarError extends Error` (base class) -- call `Object.setPrototypeOf(this, RegistrarError.prototype)` in constructor
   - `RegistrarUnavailable extends RegistrarError` -- registrar API down or unreachable
   - `DomainTaken extends RegistrarError` -- domain already registered (accepts domain string)
   - `InvalidTLD extends RegistrarError` -- TLD not supported (accepts tld string)
   - `RegistrarAuthError extends RegistrarError` -- invalid API credentials or IP not whitelisted
   - `RegistrarRateLimitError extends RegistrarError` -- rate limit exceeded (accepts retryAfter?: number)

   Every error class MUST call `Object.setPrototypeOf(this, ClassName.prototype)` -- without this, `instanceof` checks fail in TypeScript when extending Error.

**Namecheap adapter** (`apps/api/src/integrations/registrar/namecheap.ts`):

Create `NamecheapRegistrar extends DomainRegistrar` with constructor accepting:
- `apiUser: string`
- `apiKey: string`
- `clientIp: string`
- `sandbox: boolean` (default: false)

Internal helper `private async callApi(command: string, params: Record<string, string>): Promise<string>`:
- Build URL from `this.sandbox ? 'https://api.sandbox.namecheap.com/xml.response' : 'https://api.namecheap.com/xml.response'`
- Set query params: ApiUser, ApiKey, UserName (same as ApiUser), ClientIp, Command, plus all passed params
- Fetch the URL, return response text (XML)
- On non-200 HTTP status, throw `RegistrarUnavailable`
- On fetch failure (network error), throw `RegistrarUnavailable`

Internal helper `private parseXmlErrors(xml: string): void`:
- Check if XML contains `<Errors>` element. Namecheap returns errors inside `<Errors><Error Number="NNNN">message</Error></Errors>`.
- Use simple string matching / regex (no XML parser library needed for this structure):
  - Extract error number and message from `<Error Number="(\d+)">(.*?)<\/Error>` regex
  - Error 2030280: throw `DomainTaken` (domain unavailable)
  - Error 1011150: throw `RegistrarAuthError` (authentication failed)
  - Error 500000+: throw `RegistrarRateLimitError` (too many requests)
  - Other errors: throw `RegistrarError` with the message

Implement all 6 methods:
- `checkAvailability`: Command `namecheap.domains.check`, param `DomainList: domain`. Parse `<DomainCheckResult Domain="..." Available="true/false" IsPremiumName="true/false" />` from response.
- `getPrice`: Command `namecheap.users.getPricing`, params `ProductType: DOMAIN, ProductCategory: DOMAINS, ProductName: register, ActionName: REGISTER`. Extract price from `<Price Duration="1" ... YourPrice="X.XX" />`. TLD extracted from domain string.
- `register`: Command `namecheap.domains.create`, params include DomainName, Years, plus all contactInfo fields mapped to Namecheap's field names (RegistrantFirstName, RegistrantLastName, etc. -- same prefix for Registrant, Tech, Admin, AuxBilling). Parse `<DomainCreateResult Domain="..." Registered="true" ... OrderID="..." TransactionID="..." />`.
- `getStatus`: Command `namecheap.domains.getInfo`, param `DomainName: domain`. Parse `<DomainGetInfoResult Status="..." />`.
- `setDnsRecords`: Command `namecheap.domains.dns.setHosts`. Map DnsRecord[] to numbered params: `HostName1`, `RecordType1`, `Address1`, `TTL1`, etc.
- `getDnsRecords`: Command `namecheap.domains.dns.getHosts`. Parse `<host>` elements from response.

For XML parsing: Use regex extraction, NOT a library. Namecheap XML is simple and predictable. Example: `const match = xml.match(/Available="(true|false)"/);`
